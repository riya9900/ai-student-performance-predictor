**How these copies were obtained:** the UCI server could not be reached from the environment where the
project was built, so the two CSV files were downloaded from a public GitHub copy of the same dataset
(`arunk13/MSDA-Assignments`). Row counts (395 / 649), 33 columns and mean final grades match the figures
published for the UCI dataset. If you want to be 100% sure, download the official zip from the UCI page
above and compare the files (`certutil -hashfile student-mat.csv SHA256` on Windows).

`processed/` is generated by `python -m ml.train` and is not committed to Git.
