# AI Student Performance & Learning Predictor

**Live Demo:** [AI Student Performance & Learning Predictor](https://ai-student-performance-predictor-tau.vercel.app/)

## About
A full-stack AI/ML web application that predicts student academic performance using academic records and study-related inputs. It helps students understand their performance, identify potential risks, and improve their learning habits.

## Key Features
- Academic performance prediction using Machine Learning.
- Student academic risk assessment.
- Personalized learning recommendations.
- Interactive dashboard with performance charts.
- Prediction history tracking.
- Responsive and user-friendly interface.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Python, FastAPI
- **Machine Learning:** Scikit-learn, Pandas, NumPy
- **Database:** SQLite
- **Deployment:** Vercel, Render

## Machine Learning
Trained using the UCI Student Performance dataset. Multiple algorithms were evaluated, with Random Forest selected as the best-performing model.
